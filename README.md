# Binance Square Signal Bot — AI-first edition

Бот сканирует ликвидные пары Binance, проверяет сигнал на нескольких таймфреймах, рассчитывает вход, три цели и стоп, затем публикует короткий пост в Binance Square.

## Что изменено

- Мистрал теперь создаёт сразу несколько вариантов подачи за **один API-запрос**, а не слегка переписывает длинный шаблон.
- Цены и рыночные факты модель не пишет самостоятельно. Она получает закрытый каталог рассчитанных фактов и выбирает только их идентификаторы.
- Код сам вставляет неизменяемые блоки `Вход`, `Цели`, `Стоп-лосс` и `R/R`.
- В каждом посте тикер `$TICKER` встречается от одного до трёх раз; по умолчанию — один раз.
- Любая неизвестная цифра, новость, инсайд, обещание доходности или неподтверждённое утверждение отклоняет AI-вариант.
- Средняя длина резервных постов в офлайн-тесте — около 600 знаков вместо примерно 1000.
- Если Mistral временно недоступен, бот не падает: используется короткий безопасный генератор.
- По умолчанию публикуется один понятный график вместо пары перегруженных изображений.
- GitHub Actions запускает бота трижды в день; публикация происходит только при прохождении строгих фильтров.

## GitHub Secrets

В репозитории откройте `Settings → Secrets and variables → Actions` и создайте:

- `SQUARE_API` — ключ Binance Square OpenAPI;
- `MISTRAL_API` — ключ Mistral API.

Workflow находится в `.github/workflows/run.yml`. Его можно запустить вручную через `Actions → Binance Square Signal Bot → Run workflow`.

## Локальный запуск

```bash
python -m venv .venv
source .venv/bin/activate       # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
python self_test.py
python main.py
```

Для проверки без публикации оставьте в `.env`:

```env
DRY_RUN=1
```

Для реальной публикации:

```env
DRY_RUN=0
SQUARE_API=ваш_ключ
MISTRAL_API=ваш_ключ
```

Файл `.env` загружается автоматически и исключён из Git.

## Режимы генерации

```env
CONTENT_MODE=ai_first       # Mistral, затем безопасный fallback
CONTENT_MODE=deterministic  # только локальный короткий генератор
```

## Медиа

```env
PUBLISH_MEDIA_MODE=chart  # рекомендованный вариант
PUBLISH_MEDIA_MODE=card
PUBLISH_MEDIA_MODE=both
PUBLISH_MEDIA_MODE=none
```

## Проверки безопасности текста

Перед публикацией бот проверяет:

- обязательные уровни и точные значения;
- направление LONG/SHORT;
- от одного до трёх упоминаний тикера `$TICKER`;
- ровно один вопрос аудитории;
- не более двух хэштегов;
- отсутствие выдуманных чисел и неподтверждённых заявлений;
- длину, читаемость и сходство с предыдущими публикациями.

## Важное ограничение

Код способен улучшить качество, оригинальность и читаемость публикаций, но не может гарантировать просмотры или реакции: распределение охватов зависит также от аккаунта, времени публикации, темы, истории аудитории и алгоритмов платформы.
